CareSync | Hack4Good 2026

Repo Link

CareSync is a real-time companion dashboard for caregiver support. It takes in device feedback events, streams live updates to the UI, and uses a lightweight ML pipeline to predict the next likely need.

The project uses 2 ESP32 microcontrollers acting as wearable devices, to allow the elderly residents to quickly communicate needs to their designated caregiver. Using UDP for the lowest overhead, button presses are sent from elderly device to caregiver device, which then sends the event to a backend server for easy tracking by the caregiver.

An LED on both devices lights up with a corresponding colour for different needs, such as "Tired", "Pain", and "Happy". These alerts can be customised for different users

First finals run in a hackathon, was just happy to be there. Unfortunate we didn't podium, but good experience pitching nonetheless!


Alex to the Rescue | CG2111A

Repo Link

The project is a search-and-rescue robot designed to navigate a simulated lunar environment and locate a target. It uses LiDAR for environment sensing and mapping, allowing the robot to detect obstacles and navigate around them. The Raspberry Pi handles higher-level navigation and communicates with the Arduino through TCP/IP with TLS for secure data transmission.

The Arduino handles the low-level hardware controls and executes movement commands from the Raspberry Pi. The robot controls four motors for movement and uses encoders for motion feedback. It also controls a robotic arm for interacting with objects, with sensors providing feedback to coordinate the robot's actions.
