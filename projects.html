01 / DESKTOP SOFTWARE

OpenSuite

A local-first workspace for editing PDFs and making presentations.

OpenPDF handles PDF text, page operations, annotations, redaction, forms, and OCR. OpenSlides provides a drag-and-drop slide canvas with editable PowerPoint export; Ask Claudia turns prompts into slide changes through the Claude API. Built as part of a team hackathon project.

Python · React · Electron · Claude API

02 / COMPUTER VISION

EventLogger

A Raspberry Pi camera that records who it sees and sends Telegram alerts.

Built in C++23 with OpenCV. YuNet finds faces; SFace compares them against enrolled images. Presence tracking uses timeouts and cooldowns so each frame does not become a new event. Separate threads handle the camera, event queue, and Telegram bot. Events are also logged locally. “Entered” and “left” mean camera observations, not confirmed movement through a doorway.

C++23 · OpenCV · Raspberry Pi 5 · Telegram
Source code
03 / EMBEDDED + WEB

PetPal

A pet care dashboard designed to talk to a physical feeder and play device.

The project connects an ESP32 device to a Next.js dashboard through an Express API. The interface sends feed and play commands and reads device telemetry. A simulator can stand in for the hardware during development, so the dashboard and API can be tested independently. The device code lives alongside the web stack in the CG2271 assignment repo.

ESP32 · Next.js · Express · Simulator
Source code
04 / DIGITAL DESIGN

Tamagoonchi

A virtual pet running on a Basys 3 FPGA board.

Written in Verilog for NUS EE2026. One OLED shows the pet and its hunger, happiness, and experience; a second hosts mini-games including Connect 4 and Flappy Mushroom. Buttons, switches, LEDs, a seven-segment display, and a wired mouse provide input and feedback. The design manages pet state and display timing directly on the FPGA.

Verilog · FPGA · OLED · SPI
Source code
05 / WEB APP

PathFinders

A web app for finding running routes that suit your preferences.

PathFinders combines a React frontend with a Node backend to generate personalised routes. The repository includes geographic tooling with Turf and encoded route handling with Mapbox Polyline. It is a team project with a public web demo.

React · Node.js · Turf · Maps

06 / EMBEDDED CARE

CareSync

Wearables that help residents tell caregivers what they need.

Two ESP32 devices send button presses over UDP. Coloured LEDs confirm a resident’s signal, such as pain or tiredness, while the caregiver device passes it to a backend and live dashboard. The prototype also explores predicting likely next needs. Our team reached the Hack4Good 2026 finals.

ESP32 · UDP · Dashboard · ML prototype
Source code
07 / ROBOTICS

Alex

A teleoperated search and rescue robot for a simulated lunar environment.

LiDAR maps obstacles for navigation. A Raspberry Pi sends higher-level commands to an Arduino over TCP/IP with TLS; the Arduino controls four motors, wheel encoders, and a robotic arm. The team project brought sensing, communication, and hardware control together in a robot that had to move reliably.

Raspberry Pi · Arduino · LiDAR · TLS
